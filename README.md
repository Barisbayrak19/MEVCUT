# MEVCUT

**Dijital Yoklama ve Devamsızlık Sistemi**

MEVCUT, öğretmenlerin yoklamayı hızlıca girmesini ve okul yönetiminin yoklama kayıtlarını e-Okul'a aktarabilmesini hedefleyen web uygulamasıdır.

## Mimari

- React + TypeScript + Vite
- Firebase Authentication
- Cloud Firestore
- Chrome Extension / e-Okul Bridge
- GitHub Pages

## Geliştirme durumu

🚧 MVP geliştirmesi başladı.

İlk hedef: öğretmen → yoklama → Firestore → yönetici → e-Okul Bridge akışını kurmak.
